ARYA PORTFOLIO — ROOT FILES EDITION

Files (all in the repository root):
- index.html
- style.css
- script.js
- README.txt

GitHub Pages setup:
1. Upload these four files directly into the root of your repository. Do not upload the enclosing ZIP folder.
2. Open Settings > Pages.
3. Choose Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for the Pages build to finish in the Actions tab.

The hero planet is drawn locally in canvas (no external API or image needed). Drag it to rotate, use the pause button to stop/start rotation, and the reset button to return it to the starting angle.

The contact form prepares an email in the visitor's email app; it does not send anything automatically. The project tiles are sample concepts and should be replaced with real work when available.
